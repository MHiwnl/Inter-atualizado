# Destino após login, Contratar no menu e menu do usuário

**Situação:** concluída em 2026-11-07
**Pedido do usuário:**
- Depois do login, cliente vai para Contratar e profissional vai para Oportunidades, e não para o painel.
- Contratar entra no menu, entre Como Funciona e Para Profissionais; sem login, leva para Entrar e depois segue o destino acima.
- No cabeçalho, o botão "Painel" mostra o nome do usuário e abre duas opções: entrar no painel e sair da conta.
**Usar:** a skill `impeccable`.
