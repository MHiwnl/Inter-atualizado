# Animar o site inteiro

**Situação:** concluída em 2026-11-07
**Pedido do usuário:** usar o Impeccable para animar o site inteiro.
**Usar:** a skill `impeccable`, comando `animate`.

## Fazer
- [x] Definir uma linguagem de movimento única para o site, coerente com o `DESIGN.md`.
- [x] Páginas públicas: entrada do topo, revelação das seções ao rolar, troca de página.
- [x] Componentes: botões, links com seta, FAQ, pedido de exemplo, menu móvel, modais e avisos.
- [x] Painel: movimento discreto, só para dar retorno às ações.
- [x] Respeitar o movimento reduzido e nunca esconder conteúdo se o JavaScript falhar.
- [x] Testar desempenho, teclado e celular; atualizar o `DESIGN.md`.
